# Aprendizados

Durante o desenvolvimento deste projeto, aprendi os principais conceitos de Git e GitHub.

## O que aprendi

- A diferença entre Git e GitHub.
- Como criar e organizar um repositório.
- Como realizar commits.
- A importância dos commits atômicos.
- Como utilizar branches.
- A diferença entre `git pull` e `git fetch`.
- Como criar e utilizar Pull Requests.
- Como identificar e resolver conflitos.

## Reflexão

A utilização do Git e do GitHub permite organizar melhor o desenvolvimento de projetos, acompanhar alterações e colaborar com outras pessoas. A prática com branches, commits e Pull Requests ajudou a compreender melhor o fluxo de trabalho com controle de versão.
