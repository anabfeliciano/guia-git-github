# Módulo 1 — Introdução ao Git

## O que é Git?

Git é um sistema de controle de versão distribuído utilizado para acompanhar alterações em projetos.

## O que é GitHub?

GitHub é uma plataforma online que permite hospedar, compartilhar e colaborar em repositórios Git.

## Comandos básicos

### git init

Inicializa um novo repositório Git.

### git add

Adiciona alterações à área de preparação.

### git commit

Registra as alterações no histórico.

### git push

Envia commits locais para o repositório remoto.

### git pull

Baixa alterações do remoto e integra essas alterações ao repositório local.

### git fetch

Baixa informações do repositório remoto sem alterar imediatamente os arquivos do diretório de trabalho.
